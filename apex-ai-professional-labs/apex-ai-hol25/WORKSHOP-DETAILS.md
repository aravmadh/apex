# Workshop Details

Estimated Time: 35 minutes

## Short Description

Make Employee Self-Service (ESS) an installable Progressive Web App. Add secure notification and location patterns.

## Long Description

Employees use ESS for onboarding tasks, leave requests, payslips, and profile updates.

Enable ESS as a Progressive Web App. Configure its install experience. Then tune its high-value pages for small screens.

Add PWA shortcuts, install screenshots, native sharing, consent-based location capture, and opt-in push notifications.

Test persistent authentication separately. Keep browser capabilities separate from APEX security controls.

## Workshop Outline

1. Introduction
2. Lab 1 - Enable PWA on ESS
3. Lab 2 - Add PWA Enhancements
4. Lab 3 - Test Persistent Authentication
5. Lab 4 - Enable Push Notifications
6. Lab 5 - Optimize Key ESS Pages
7. Lab 6 - Review APEXToGo Patterns

## Workshop Prerequisites

- Complete Modules 3 through 24.
- Verify ESS, My Tasks, Leave Request, My Profile, the onboarding pages, and the Module 16 automation.
- Access to ESS in Oracle APEX 26.1 with developer privileges to edit application attributes, shared components, pages, and automations.
- An HTTPS APEX environment (or localhost for development) and **Friendly URLs** enabled for ESS.
- Use a browser or device that supports PWA installation.
- A mobile device or browser emulation works well for mobile validation.
- Obtain approved ESS icons at 192 by 192 and 512 by 512 pixels. Also obtain two approved screenshots.
- This repository does not include those assets.
- Ask an instance administrator for persistent-authentication settings and a push-notification signing credential.
