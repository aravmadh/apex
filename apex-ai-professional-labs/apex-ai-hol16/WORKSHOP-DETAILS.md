# Workshop Details

## Short Description

Extend ESS and TAP with native APEX components, Signature Capture, scheduled automations, and reusable email templates.

## Long Description

In this 60-minute module, learners add a leave calendar and a 30-Day Check-In survey to ESS. They configure ESS email templates, automations, and an administrator System Logs report. Learners also add a TAP interview calendar, retain the approved Signature Capture component for offers, build TAP email templates, and automate interview and offer notifications.

The module ends with an overview of application translation. It does not create a translated application.

## Workshop Outline

1. Create the ESS Leave Calendar.
2. Create the ESS 30-Day Check-In Survey.
3. Create ESS Email Templates.
4. Create ESS Scheduled Automations.
5. Create the ESS System Logs Page.
6. Create the TAP Interview Calendar and capture offer signatures.
7. Create TAP Email Templates.
8. Create TAP Scheduled Automations and review translation.

## Prerequisites

- Complete Modules 10 through 15.
- Ensure that ESS and TAP share the specified `TMS_` tables.
- Ensure the approved Signature Capture plug-in is available in TAP.
- Have an instance administrator available to configure email delivery when required.
- Ensure the parsing schema has the required privileges for scheduled automations.
