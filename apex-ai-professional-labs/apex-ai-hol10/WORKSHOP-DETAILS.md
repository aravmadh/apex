# Workshop Details

## Short Description

Create shared LOVs and configure practical page items for the Talent Acquisition Portal and Employee Self-Service Portal.

## Long Description

This 20-minute module continues the TAP and ESS work from Module 8. Learners create reusable lists of values, configure an Offer Management form, create an Interview Feedback form, and build an ESS Leave Request form with a leave-history report.

Module 11 adds the computations, validations, and DML processing that make these configured forms save data correctly.

## Workshop Outline

1. Create TAP and ESS shared-component LOVs.
2. Configure the TAP Offer Management form.
3. Build and link the TAP Interview Feedback form.
4. Build the ESS Leave Request form and My Leave History report.

## Prerequisites

- Complete Module 8, including the TAP Interview Schedule and ESS My Tasks interactive grid.
- Complete Module 5, including the TAP Offers page and base ESS Leave Request page.
- Use the TMS schema created in Module 2.
