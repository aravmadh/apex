# Workshop Details

## Short Description

Use APEXlang and Spec-Driven Development to scaffold and evaluate a comparison version of the Talent Acquisition Portal before building the course application with the Create App Wizard.

## Long Description

This 90-minute foundation module introduces the APEXlang source format and an SDD workflow. Learners export an existing application, prepare a TAP functional specification, schema metadata, Blueprint Prompt, and allowed-icons list, then use a coding agent to generate an Application Blueprint.

Learners import and run the generated TAP only to compare approaches. The course continues in Module 5 with a Wizard-built TAP, which provides the UI control needed to teach APEX components directly. Modules 23 and 24 return to APEXlang by exporting that Wizard-built application.

## Workshop Outline

1. Export and inspect an application with APEXlang.
2. Set up the TAP SDD artifacts and coding agent.
3. Generate and review a TAP Application Blueprint.
4. Import, run, and set aside the comparison TAP.

## Prerequisites

- An APEX workspace with the Module 2 TMS schema and Module 3 Sample Application (APEXToGo).
- A local coding workspace with a coding agent and SQL Developer extension.
- Course-provided `tms_module_04_functional_spec.md` and `apex-fa-icons-allowlist.txt` files.
